# Customer Retention & Churn Analysis

## 📊 Project Overview
This project focuses on analyzing customer churn and retention patterns for a subscription-based business. The objective is to understand why customers leave and identify key factors that influence customer retention.

## 🎯 Objective
- Analyze customer churn behavior
- Identify high-risk customer segments
- Understand customer lifetime patterns
- Provide actionable recommendations to improve retention

## 🛠️ Tools Used
- Power BI
- Excel

## 📁 Dataset
- Telco Customer Churn Dataset (Kaggle)

## 📈 Key Metrics
- Total Customers
- Churned Customers
- Churn Rate (%)

## 📊 Analysis Performed
- Churn rate calculation
- Customer segmentation (Contract, Payment Method, Internet Service)
- Tenure-based churn analysis
- Pricing vs churn behavior

## 🔍 Key Insights
- Customers with month-to-month contracts show the highest churn rate.
- New customers (low tenure) are more likely to churn compared to long-term customers.
- Higher monthly charges are associated with increased churn probability.
- Certain payment methods show higher churn patterns, indicating possible friction in billing experience.

## 💡 Recommendations
- Encourage long-term contracts with discounts and incentives.
- Improve onboarding experience for new customers to reduce early churn.
- Optimize pricing strategies for high-risk customer segments.
- Introduce loyalty programs and personalized offers for retention.
